Connect your worker

The scripted demos work immediately. For cloud AI, create a Gemini key in Google AI Studio ↗.

For local AI, install Ollama, download the model, and select Ollama · local AI. No API key is required.

ollama pull qwen3.5:4b

Set AI_PROVIDER=ollama and OLLAMA_MODEL=qwen3.5:4b in .env, then restart the server. Ollama must be running.

  1. Copy .env.example to .env.
  2. Set GEMINI_API_KEY=your_key.
  3. Restart with npm start.
npm install
npm run setup:browser
npm start

Gemini mode sends observed page and file content to Google. Local Ollama mode sends model requests to the Ollama service on this computer. External websites still use the internet. The agent can read and summarize Excel, Word, OpenDocument, and modern PowerPoint files. On macOS it can open documents in their default apps. Office source files remain read-only. External folders are available when all-files mode is enabled. Controlling native app windows, PDF OCR, and arbitrary shell commands are outside its current toolset.
